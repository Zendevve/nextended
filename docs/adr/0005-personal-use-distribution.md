# Personal-use distribution; no store listing

nextended could be published to the Chrome Web Store / AMO (the copyright holder is not
bound by its own license), but we decided its audience is the maintainers' own browsers:
unpacked install, all-rights-reserved personal-use license, no store presence.

## Considered Options

- **Publish publicly** — rejected for now: it imports review processes, a selector-rot
  update cadence owed to strangers, Nexus ToS exposure, and a support queue, while the
  personal-use license reads oddly beside a store listing.

## Consequences

"Renders the replaced userscripts irrelevant" is measured against the maintainers' own
setups, not market share. No telemetry, crash reporting, or update infrastructure gets
built. Revisit only if the personal bar is met and an audience is still wanted — cheap
to decide later, expensive to unwind.
